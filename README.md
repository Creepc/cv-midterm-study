# VISION NOTE

컴퓨터비전 중간고사를 위한 한국어 학습 사이트입니다. 제공된 강의자료 4개와 학습진단·연습문제 5개를 분석해 구성했습니다.

## 먼저 볼 내용과 참고 자료

첫 화면은 **주별 학습진단 핵심 18항목**을 우선 표시합니다. `주별 핵심 개념`에서 2·3·4·7주차별 정의, 계산 예, 주의점과 원문 문제를 함께 보고, `강의자료 전체 정리`에서 PPT 4개를 자료별로 펼쳐 볼 수 있습니다. `원본 자료 · 검토 내역`에는 원본 9개의 목차와 정정·보완 근거를 따로 모았습니다.

2026-10-20 재대조 기준: 49개 개념, 159문항, 지정 연습문제 8개. 주별 원문 18항목과 75개 이론 슬라이드, 87개 실습 슬라이드를 대응했습니다. 기존 문항 ID는 유지했습니다. 기존 문항의 수치 정답에서 계산 오류는 발견하지 않았으며, 부족한 해설과 코드에 대입하면 틀리는 허용 답안을 보완했습니다. 결과 예측 50개 중 48개는 코드·명시 계산으로 검증하고 GUI 조건의 2개는 문서·조건을 대조했습니다.

## 학습 기능

- 주별 핵심 개념: 원문 18항목을 한 페이지 요약으로 보고 필요한 설명만 펼치기
- 강의자료 정리: PPT별 폴더, 상세 원리와 추가 범위, 정확히 연결한 관련 문제
- 문제 풀이: 원문·변형, 객관식·코드 빈칸·결과 예측·서술형, 힌트와 단계별 해설
- 4장 집중 학습: 연습문제 **1, 2, 5, 6, 9, 10, 13, 16**번의 수정 풀이와 상세 설명
- 코드 실험실: 좌표·ROI, BGR 색상, uint8 덧셈, 마우스 콜백, 히스토그램/CDF 조작
- 오답 노트: 문항별 마지막 풀이 기준, 재풀이 및 북마크
- 모의고사: 범위·유형·문항 수·시간 선택, 자동 제출, 일괄 채점과 서술형 자기평가
- 학습 기록: 브라우저 저장, JSON 내보내기·가져오기
- 모바일 화면, 키보드 접근, 전체 검색(`/` 단축키)

## 범위

이론: 디지털 이미지 / 샘플링 및 양자화 / 이미지 강화 기법. 2·3·4·7주차 학습진단문제를 포함합니다.

실습: CH_04의 윈도우, 이벤트, 그리기, 영상 I/O, 비디오, Matplotlib 전체. 코드 결과는 제시된 조건과 자료형을 기준으로 설명합니다. 수업 중 구두 강조 내용은 자료만으로 확인할 수 없으므로 지정 연습문제를 우선합니다.

과제 답안의 오타, `shift`, PNG 압축과 화질, 카메라 입력, ROI 끝 좌표, NumPy와 OpenCV 덧셈 차이를 검토해 정정했습니다. 학습용 평활화는 강의의 `round((L-1)*CDF)` 규칙을 명시해 OpenCV의 구현과 구별합니다.

## 로컬 실행

Node.js 20 이상이 필요합니다. 외부 패키지 설치는 필요 없습니다.

```sh
npm test
npm run build
npm run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. `dist/index.html`을 직접 열어도 사용할 수 있습니다(클립보드 등 브라우저 권한은 환경에 따라 제한될 수 있습니다).

## GitHub Pages

`.github/workflows/pages.yml`이 `main` 푸시 시 검증·빌드 후 `dist/`를 배포합니다. 저장소 Settings → Pages의 Source는 **GitHub Actions**로 설정합니다. 상대 경로와 해시 라우팅을 사용하므로 프로젝트 하위 경로 배포에 대응합니다.

## 자료와 기록

콘텐츠는 `data/weekly.json`, `data/theory.json`, `data/practice.json`, `data/sources.json`, `data/audit.json`에 있습니다. 원본 PPTX·PDF·DOCX와 과제 제출자의 학번·이름은 공개 배포에 포함하지 않습니다. 자료 출처의 파일명은 식별용이며 다운로드 링크가 아닙니다. 원문 태그는 조건을 유지한 학습용 전사이며 실습 문항을 세부 질문으로 나누기도 했습니다. 변형은 새로 만든 연습 문제입니다.

실험실은 브라우저 시뮬레이션이며 Python 실행기가 아닙니다. 서술형은 모범답안 비교 후 자기평가합니다. 코드 빈칸은 식별자·대소문자·괄호·따옴표를 보존해 비교합니다. 행렬 등 수치 출력은 원소 순서를 유지하며 표시 공백 차이를 허용합니다. 자동채점은 미리 정의한 답과 대체답을 비교하므로 표현이 다른 답은 해설과 함께 확인해야 합니다. 진행 중인 모의고사는 새로고침하면 종료됩니다. 기록은 현재 브라우저에만 저장되므로 다른 기기로 옮길 때 내보내기를 이용하세요.

이미지는 코드로 그린 UI 요소만 사용합니다. 폰트는 Google Fonts에서 불러오며 오프라인에서는 시스템 글꼴로 표시됩니다.
